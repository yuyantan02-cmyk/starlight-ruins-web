# 《星灯遗迹》电脑版正式版 v1.0.0

这是用于验证游戏手感、菜单、难度和第一关节奏的可玩原型，不是最终生产版本。

## 产品定位

当前版本是纯单机游戏，全部玩法、图片和运行文件都保存在本地，不需要联网。后续开发双人联机版本时，再独立增加网络服务；单机模式继续保留离线可玩。

## 打开方式

macOS 可直接双击 `index.html`，使用 Chrome、Edge 或 Safari 打开游玩，不需要安装依赖。

Windows 推荐下载单独的 `星灯遗迹_Windows_x64_离线版.zip`，完整解压后双击 `StarlightRuins.exe`。该版本已内置运行环境，无需 VPN、无需联网。

如果浏览器限制本地功能，也可以在本目录运行：

```bash
python3 -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。

## 默认操作

- A / D：左右移动
- W / S：选择冲刺方向；第十关同时调整手电筒照射角度
- 空格：跳跃、二段跳
- 左 Shift：冲刺
- Esc：暂停
- 手柄左摇杆：移动与冲刺方向
- 手柄 A：跳跃
- 手柄 X 或 B：冲刺
- 手柄菜单键：暂停

所有键盘按键都可以在“设置”中重新绑定。

## Android 安装版

Android 版与电脑版共用本目录中的同一份游戏资源和关卡逻辑，Capacitor 容器位于 `mobile/android-app/`。当前发布版为纯单机离线应用，无需联网，也不申请网络权限。

安卓 APK、商店 AAB、固定签名及以后更新版本的操作说明见 `mobile/android-app/README-ANDROID.md`。日常开发仍只修改本目录，再由构建脚本同步到 Android 工程。
